# 身份：按网络场景替换地址和端口

同一台服务器在不同网络下的访问方式可能不同，比如公司内网直连 `192.168.10.105:22`，在外面要走 frp 穿透 `frp.example.com:6022`，或者经过代理映射出来的端口。身份就是用来记录这些差异的。

1. 打开「设置 → 身份」，点「新建身份」，填写名称（例如“frp 穿透”）。确定后进入这个身份的规则页。
2. 点「添加规则」，选择要替换的 SSH 连接，填写新的地址和/或端口。只填一项时，另一项沿用连接自己的设置。点规则可修改，点删除图标可移除；没有规则的连接不做替换。
3. 回到身份列表，选中这个身份前面的单选按钮。选「默认」则所有连接使用自己的地址和端口。

切换身份后，新建的连接和重新连接按新身份拨号，已打开的会话不受影响。中转主机也遵循当前身份：中转主机和目标主机各自按身份里的设置替换地址。

主机指纹仍按连接自己保存的地址和端口校验，通过穿透或代理访问同一台服务器时不需要重新确认指纹；如果替换后的地址连到的其实是另一台服务器，会按指纹变化提示。

身份的名称和地址／端口替换规则会通过 WebDAV 或 GitHub Gist 随连接一起加密同步。当前选中的身份只保存在本机，每台设备按自己的网络环境选择；仅切换身份不会触发上传。

在一台设备删除身份后，其他设备同步时也会删除它；如果本机正在使用这个身份，会自动回到「默认」。同一身份在两端同时修改时，需要在同步冲突提示中选择保留哪一端的版本。

规则引用的连接被删除后，规则仍保留，显示为「已删除的连接」，可以手动清理。

含身份的同步数据使用新版格式，旧客户端无法读取。使用身份同步前，请先将参与同步的所有设备升级到支持此功能的版本；已有不含身份的同步数据仍可读取。
