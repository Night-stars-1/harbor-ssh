# 端口转发

打开首页独立的 **端口转发** 标签页：桌面端位于左侧导航，手机端位于底部导航，与 SFTP 同级。页面统一显示各主机的转发规则。点击顶部 **添加规则**，在弹窗中选择 **SSH 主机** 和 **转发类型**，无需先建立 SSH 连接即可保存。编辑已停止的规则时也可以更换主机。

终端右上角 **终端选项 → 端口转发**，以及会话右键菜单（手机上长按会话）中的同名入口，都会跳转到该标签页，为添加弹窗预选对应主机，并在启动时优先复用该会话。

添加规则并保存，然后点击 **启动**。已有 SSH 连接时复用会话；未连接时进入现有登录流程，认证成功后启动转发。取消登录不会启动规则。监听端口填写 `0` 时自动分配，启动成功后列表显示实际端口。运行中的规则需先停止，再编辑或删除。

| 类型 | 监听位置 | 目标地址相对于 | 示例 |
| --- | --- | --- | --- |
| 本地转发 | 此设备 | SSH 服务器 | 本机 `127.0.0.1:15432` → 服务器侧 `127.0.0.1:5432` |
| 远程转发 | SSH 服务器 | 此设备 | 服务器 `127.0.0.1:8080` → 本机侧 `127.0.0.1:3000` |
| SOCKS5 代理 | 此设备 | SSH 服务器 | 应用使用 SOCKS5 `127.0.0.1:1080`，通过服务器访问目标 |

- 转发复用选中的已认证 SSH 连接。切换标签页后继续运行，断开或关闭会话时全部停止。
- 规则按主机保存在当前设备，不同步到云端，重连或重启后不会自动启动。同一主机的不同 SSH 会话独立运行；固定端口只能由一个监听占用。
- 默认监听回环地址，只允许本机访问。本地转发绑定 `0.0.0.0` / `::` 会向其他设备开放端口，是否可达还受系统防火墙控制。
- 远程转发需服务器允许 TCP 转发，实际监听范围受服务端 `GatewayPorts` 配置控制。
- SOCKS5 仅支持无认证 TCP CONNECT，不支持 UDP；为此只允许回环监听。若需由服务器解析域名，在使用代理的应用中启用“通过代理解析 DNS”（例如 `socks5h`）。
- 启动失败会显示原因，可修正规则后重试。目标暂时无法访问不会关闭本地或远程监听；后续连接可再次尝试。
- 如果服务器拒绝停止远程监听，规则保留运行状态，可重试或断开 SSH。服务器启动请求超时且无法确认远程监听状态时，SSH 会话会关闭以释放可能已创建的监听。

## 开发验证

`test/port_forward_test.dart` 测试规则、存储和启停生命周期；`test/port_forward_widget_test.dart` 测试交互与窄屏布局。

安装 `tool/requirements-test.txt` 中的 Python 测试依赖，设置 `HARBOR_SSH_INTEGRATION=1` 后运行 `flutter test test/port_forward_integration_test.dart`。该测试仅连接本机临时 Paramiko 服务器，不读取用户凭证或访问真实主机。
