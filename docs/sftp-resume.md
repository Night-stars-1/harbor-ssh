# SFTP 断点续传

上传、下载和双面板文件夹复制均可在传输时点击暂停，随后点击继续，从已确认写入的位置接着传输。连接中断或服务器响应超时时保留断点；重新连接原来的主机后点击继续即可。

双面板中的批量任务会跳过已完成的项目，文件夹复制会保留已完成的子文件。覆盖传输时，旧文件或文件夹会保留到新内容全部传完。暂停期间不能关闭任务使用的标签，可重新连接主机。

桌面端可将外部文件夹中的文件或整个文件夹拖到 SFTP 面板，上传到该面板当前显示的目录；可一次拖入多个项目，无需新增本地标签。已有同名项目时先确认覆盖；一批来源中含同名项目或符号链接时拒绝操作。文件夹中的符号链接同样不支持。外部来源也支持暂停、继续和放弃，暂停后不要移动、修改或删除源项目；macOS 的拖入目录访问权限保留到传输完成或放弃。切换到终端或设置页面后不会接收上传拖放。

手机文件页面可以暂停后返回终端，重新连接，再回到同一会话的文件页面继续。Android 下载先写入应用的本地缓存，传完后选择保存位置；上传的文件若没有可随机读取的本地路径，会先准备一份缓存。因此手机需要足够的本地可用空间。

继续时会核对源文件大小、修改时间、文件开头和断点附近的数据，并检查传输缓存。源文件或缓存发生变化时停止续传，需放弃后重新开始。文件夹的内容变化也会停止续传。普通文件大小未知、符号链接及其他特殊文件不能安全续传。

点击放弃会清理本次任务的临时文件，已完成并发布的文件保留。上传任务需要连接原来的目标主机才能清理远端缓存。

当前断点任务保存在运行中的应用会话里：支持暂停、断线重连和返回手机终端后的恢复，不支持退出或重启应用后恢复任务。不要手动修改或删除 `.harbor-part-*` 临时文件。
